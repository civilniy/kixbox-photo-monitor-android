# KIXBOX Photo Monitor

Внутреннее Android-приложение для управленческого контроля автоматической ретуши каталога.

## Что показывает

- общий прогресс относительно 23 000 исходных фотографий;
- пройденные и оставшиеся исходники, включая фотографии ярлыков;
- текущую обрабатываемую партию;
- готовые фотографии, ручную проверку и ошибки;
- среднюю скорость за семь завершённых календарных дней;
- расчётную дату и оставшееся время до завершения;
- расходы OpenAI API, расчётный остаток кредитов и прогноз бюджета до завершения.

Дата дедлайна не задаётся. Прогноз постоянно пересчитывается по фактической скорости.

## Состав

- `app/` — Android-приложение на Kotlin и Jetpack Compose;
- `backend/` — закрытый FastAPI-сервис для чтения отчётов Google Drive и OpenAI Costs API;
- `.github/workflows/build-apk.yml` — автоматическая сборка APK.

## Получение APK

После каждого обновления ветки `main`:

1. Открыть вкладку **Actions**.
2. Выбрать последний успешный запуск **Build Android APK**.
3. Скачать артефакт **KIXBOX-Monitor-APK**.
4. Распаковать ZIP и установить `KIXBOX-Monitor.apk` на Android.

GitHub Actions сохраняет внутреннюю тестовую подпись в cache, поэтому последующие APK обычно устанавливаются поверх предыдущей версии. Если cache подписи будет утерян, Android потребует удалить старую тестовую сборку перед установкой новой.

## Запуск API

```bash
cd backend
cp .env.example .env
docker build -t kixbox-photo-monitor-api .
docker run --env-file .env -p 8000:8000 \
  -v /secure/google-service-account.json:/run/secrets/google-service-account.json:ro \
  kixbox-photo-monitor-api
```

Папку `04 Отчеты` необходимо предоставить сервисному аккаунту Google в режиме чтения.

### Основные настройки

| Переменная | Назначение |
|---|---|
| `TARGET_SOURCE_TOTAL` | Общий план исходников, сейчас `23000` |
| `GOOGLE_REPORTS_FOLDER_ID` | ID папки `04 Отчеты` |
| `GOOGLE_SERVICE_ACCOUNT_FILE` | Путь к JSON сервисного аккаунта Google |
| `OPENAI_ADMIN_KEY` | Admin API key для официального Costs API |
| `OPENAI_CREDIT_TOPUPS_USD` | Сумма всех пополнений для расчётного остатка |
| `MONITOR_API_TOKEN` | Закрытый токен приложения |
| `REFRESH_MINUTES` | Интервал обновления, по умолчанию 15 минут |

Обычный project API key OpenAI не подходит для Costs API — требуется административный ключ организации. Прямого публичного метода получения остатка prepaid credits нет, поэтому приложение показывает расчётный остаток: пополнения минус официальные расходы.

## Подключение телефона

В приложении открыть настройки и указать:

- адрес API, например `https://monitor.example.ru`;
- значение `MONITOR_API_TOKEN`.

Адрес и токен сохраняются только в локальных настройках телефона. Ключи Google и OpenAI в APK не попадают.
