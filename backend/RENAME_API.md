# API точного переименования

API выполняет сохранённый план из 1515 фотографий. Из запроса нельзя передать произвольное имя, файл или папку. Сомнительные файлы с `_ПРОВЕРИТЬ_БИРКУ` исключены. Файлы переименовываются и перемещаются без копирования; исходные имена остаются в реестре.

## Настройка

В Google Apps Script сохраните `rename_api.gs`. В свойствах скрипта задайте `RENAME_PLAN_ID` — ID JSON-реестра, и `RENAME_API_TOKEN` — случайный секрет. Публикация веб-приложения: выполнение от владельца, доступ для всех; каждый запрос проверяет секрет. Разрешения файлов не меняются. Для прямых запросов к Drive API скрипту нужно разрешение подключения к внешнему сервису.

В Render задайте `GOOGLE_RENAME_SCRIPT_URL` и тот же `RENAME_API_TOKEN`. Секрет хранится только в настройках сервисов. Код подключается к FastAPI через `main.py`.

## Запросы

Все запросы требуют заголовок `Authorization: Bearer <RENAME_API_TOKEN>`.

- `GET /api/v1/rename/status`: завершённые файлы, переименованные файлы, ошибки, время последнего сохранения и состояние очереди.
- `POST /api/v1/rename/start`: запуск либо продолжение незавершённого плана.
- `POST /api/v1/rename/stop`: остановка после текущего пакета.

Пакет содержит до 25 файлов. Метаданные, конфликты и изменения выполняются параллельными запросами Google Drive API. Перед изменениями сохраняются намерения, после изменений — результат. Повторный запуск распознаёт уже переименованный или перемещённый файл и продолжает без создания копий.

Очередь живёт в процессе Render. После перезапуска сервиса повторите `start`: реестр сохраняется на Google Drive. При конфликте или ошибке очередь останавливается для проверки. Бесплатный экземпляр может засыпать при отсутствии обращений.
